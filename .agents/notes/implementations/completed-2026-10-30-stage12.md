Status: complete; approved by the user. Scope follows [stage 12](./2026-10-29-implementation-plan.md#12-add-root-and-observation-profiles). Conditional/history composition and coordinated worker snapshots remain stage 13; recursive call frames remain stage 14.

## Decisions

The owning [observation contract](../../../docs/observation.md#coverage-and-observer-effects) defines named-roots-diagnostic, roots-diagnostic, and roots-natural. Both binding profiles capture quiescent caller locals. Controlled lifetimes use fences; natural obligations follow future semantic uses, with no fences or diagnostic array binding. Natural reference/contended histories and conditional control require path-sensitive reachability analysis and remain unsupported. Worker data/alias traces independently test semantic uses across collection and barriers; no claim is made to snapshot active worker heaps.

Version 1 snapshots opt into actual local-variable metadata with capability bit 32. Compiler -g supplies names/scopes; JVMTI queries run after callbacks without acquiring local objects. Binding presence files contain primitives only. Non-null mapping requires a unique actual method/slot/scope/thread/frame origin, never a lookup of the expected object ID. Nullness conflicting with a physical root is inconclusive. Current capture supports main worker 0, invocation 1; snapshot/control visits distinguish repeated checkpoints and binding definitions distinguish loop instances.

NaturalLiveness analyzes syntax, bounds work/storage, and kills prior definitions when tracing uses backward across loop iterations. Emission uses visit-specific guards; verification independently interprets graph/data effects and applies the declared observation policy. An independent 128-case enumeration checks use positions, including zero/last visits and fresh loop bindings. Root matching indexes metadata by actual physical slots and rejects conflicting slots, frames, and overlapping local scopes.

The [same-object instruction](../../../engine/src/main/java/io/connglli/gorrect/engine/gir/Instruction.java) performs Java reference equality with scalar 0/1 results. It records no workload references and works in exact, reference, and contended histories. Structured observation-capabilities.json reports availability, exercise, verification, effects, footprints, required evidence, and unsupported combinations. Verified semantic reads/aliases remain distinct from an inconclusive heap snapshot; reports are derived outputs, never proof inputs. Requested new mechanisms must actually execute. Probe augmentation applies only to probe; run preserves supplied GIR exactly.
