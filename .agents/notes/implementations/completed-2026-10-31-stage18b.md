# Normal array range copying

Status: complete for the first normal arraycopy slice of stage 18, with independent semantic/capture and merged-source review. [GIR](../../../docs/gir.md#instructions) owns syntax/support and [Instruction.CopyArray](../../../engine/src/main/java/io/connglli/gorrect/engine/gir/Instruction.java) defines preconditions and effects. Runtime/native/protocol formats remain unchanged.

The model validates live compatible arrays and both full literal ranges before mutation, including zero-length copies, and uses immutable pre-operation source contents for overlap. It preserves both identities, all outside-range elements, shallow target identities and object/slot/occurrence quotas. One successful copy consumes one normal step. Generated Java invokes System.arraycopy directly; bytecode and target contents are checked independently. Strong sequential controlled source is supported, while mixed/reference/concurrent/natural cases reject before incomplete-evidence exits at shared and direct checker boundaries.

Focused target checks cover six HotSpot JDK 17/21 cases and one selected OpenJ9 case. Independent expected values cover both overlap directions, shallow targets and separate storage, identities and outside-range values, zero ranges, all precondition/step rejection atomicity, integer-bound ranges and unsupported direct dispatch. Generated cases cover both binding providers, conditional recorder planning, readable value corruption and missing evidence.

Original legacy bytes are unchanged; source/artifact identities and raw evidence remain in ignored local verification state.
