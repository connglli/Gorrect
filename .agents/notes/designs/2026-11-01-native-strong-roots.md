# Native strong roots proposal

Status: unaccepted, design-only first [stage 21](../implementations/2026-10-29-implementation-plan.md#21-add-deliberate-native-roots-and-critical-arrays) slice at `70244a51e28b7a392fe115266677729e587a9357`. No production capability is implemented.

## Smallest interface

Add one optional storage qualifier: `root saved jni-global = null;`. Ordinary declarations retain static Java storage. Both kinds share the root namespace and existing plain `write-root saved h;`, `read-root recovered N saved;` and `write-root saved null;`. Initial object IDs remain declaration-only; native code cannot look up expected IDs. Extend the existing root declaration with its storage kind, rather than adding native instructions or a foreign-function interface.

Each declared slot owns zero or one strong JNI global for an ordinary object, reference array or data array. Slots last from initialization through final capture; lexical scope exit and `release` end Java bindings only. Writing null deletes the global; reading null binds a typed null. Non-null reads enforce the asserted nominal shape before committing the binding. A recovered handle supports existing fields, arrays, scalar branches, mixed int/long payloads, same-object, opaque hashes and structured monitors under their existing contracts.

Whole-source admission includes skipped bodies: strong sequential controlled profiles only, excluding volatile/atomic operations. Reference processing, workers, natural liveness, weak globals, local-frame workloads, critical arrays, calls, loaders and resurrection remain separate. No caller-frame or new memory-order contract is needed.

## Portable state and lowering

Keep native slots in [GraphMachine](../../../engine/src/main/java/io/connglli/gorrect/engine/oracle/GraphMachine.java)'s named roots and [Graph.required()](../../../engine/src/main/java/io/connglli/gorrect/engine/model/Graph.java)'s full strong closure before every GC/checkpoint. They deliberately retain targets after every Java root/handle is released. [Retirement](./2026-10-31-model-retirement.md) must explicitly reject native storage in its eligibility check until this recovery path is audited, without rejecting execution; never infer an observed native root from model state.

Generated Java routes only qualified root accesses to narrow run/slot-indexed JNI configure/read/write/close methods owned by the existing `TargetSession`. Static holders contain no substitute reference field. Preallocate at most 64 declared slots, plus one temporary replacement global; reject excess declarations before construction. Successful operations keep existing step, allocation, slot and snapshot-cell charges; resource tokens are monotone, non-reused and bounded by initialization plus steps. No new user option is needed.

Write preflights run ownership, slot, supported operand shape and token/record capacity before `NewGlobalRef`. For non-null replacement, acquire the new global first; null/error preserves the old global and aborts as native resource/execution failure, retaining any pending exception. On success publish the new handle/token, then `DeleteGlobalRef` the old handle; null deletes and clears. JNI deletion has no recoverable error return. Commit operation evidence only after success. Read uses `NewLocalRef`; for either acquisition, null from non-null strong input is failure even without a pending exception. A successful read creates an independent Java handle that survives later slot deletion. Borrowed arguments and temporary locals expire before return. Workload JNI calls request no collection/capture; VM GC may occur during JNI transitions.

Cleanup runs after final capture, before successful completion, and on partial initialization or exceptional exit; it deletes every owned global, certifies empty storage and closes the run against stale/cross-run calls. Empty-storage certification pairs the cleared table with a complete post-delete walk requiring zero workload JNI globals. Cleanup errors prevent success and preserve the original failure. Existing process deadlines bound stuck calls; crash/timeout evidence remains distinct from graph failure and cannot certify cleanup.

## Actual root evidence

[JNI](https://docs.oracle.com/en/java/javase/17/docs/specs/jni/functions.html#global-and-local-references) supplies acquisition/deletion/kind checks; [JVMTI](https://docs.oracle.com/en/java/javase/17/docs/specs/jvmti.html#jvmtiHeapReferenceCallback) reports global-root targets without identifying declared slots. Therefore a generic `JNI_GLOBAL` callback alone is insufficient.

At a quiescent cut, freeze the actual workload-owned table. Outside heap callbacks, bracket one walk with complete primitive records for every declared slot: run/capture/site/visit, slot, acquisition generation, opaque actual JNI reference value, `GetObjectRefType` and actual-target `GetTag`. Read globals directly; assign missing weak tags outside callbacks without creating another reference. Require unchanged brackets and a matching raw `JNI_GLOBAL` target multiset, including aliases; qualify per-handle multiplicity on each admitted VM build. Empty slots require complete table evidence. Never inspect deleted handles, assume reference values are unique across acquisitions/runs, interpret them as object addresses, or assume addresses survive GC. Missing attribution/multiplicity support means unsupported, without target-set exemptions for extra globals.

Select version-1 native resource evidence from source/layout, with the existing capture-record ceiling independently bounding resources, hashed with retained support; pair it with the same graph walk and existing frame evidence for both `jvmti` and `retained-class`. No legacy fallback or expected-root repair is permitted. Partial, missing, contradictory, wrong-kind, unknown-target or cross-cut evidence cannot pass; preserve independently covered refutations. Complete target disagreement is a validation failure; malformed or uncovered evidence is extraction/coverage failure. Keep the existing unexpected-global leak guard for undeclared/excess roots. Observer metadata keeps primitive facts/weak tags only; the explicit workload table alone owns deliberate globals. JNI transitions, borrowed locals, array binding and heap walking can affect escape, liveness and timing; unrelated helper roots are defects.

## Admission

Start with qualified installed HotSpot 17/21; OpenJ9 follows through shared JNI plus independent qualification, otherwise explicit unsupported. No availability/exercise/verification claim precedes its evidence. The ignored HotSpot 21 probe confirms duplicate-target callback multiplicity only; no production or cross-VM proof follows.

Require real completed GC while only a global retains the graph; replacement/null/read identity and payload checks; both metadata providers and actual global-root proof; invalid/skipped combinations, failure atomicity, partial/wrong-handle/extra-global/cleanup/quota/cross-cut negatives; hooks and old-bundle run/verify/replay compatibility. Preserve legacy generated Java/layout bytes when no native slot is declared. Collection requests and root deletion establish no reclamation or progress guarantee. Accepted contracts belong in GIR, observation, implementation and usage owners during later implementation.
